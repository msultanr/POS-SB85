# MySQL migration history

This is the active migration directory configured by `prisma.config.ts`.
Requires MySQL 8.0.16+ (enforced CHECK constraints); validated against MySQL 8.0.44.
The sibling `prisma/migrations` directory is retained as PostgreSQL history only.

The initial migration creates a new schema, not a PostgreSQL-to-MySQL data transfer.
Do not run it over existing unrelated tables or use `migrate reset` on production.
Order codes are now generated by Node crypto on every checkout attempt; the unique
index handles collisions through the existing transaction retry mechanism.
Database constraints, foreign keys, notifications, and original image bytes are preserved.
